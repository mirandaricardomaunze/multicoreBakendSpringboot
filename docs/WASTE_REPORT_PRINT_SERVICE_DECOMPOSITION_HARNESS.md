# Harness de Decomposição do WasteReportPrintService

`WasteReportPrintServiceDecompositionHarnessTest` garante que a composição PDF A4 permanece extraída em
`WasteReportDocumentRenderer`, mantendo a fachada `WasteReportPrintService` focada na recolha dos dados e
dentro dos limites físicos de linhas.
