# Harness — ciclo de documentos de IA

O teste `AiDocumentLifecycleHarnessTest` protege DL-01 a DL-12: contratos neutros, migration aditiva, fronteiras Controller/Service/Repository, tenant, permissoes, separacao de funcoes, auditoria segura e integracao desktop por HTTP.

O teste de servico `AiDocumentLifecycleServiceTest` valida transicoes, motivo de rejeicao, isolamento de tenant e preservacao de versoes.
